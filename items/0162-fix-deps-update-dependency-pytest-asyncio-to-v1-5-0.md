### [1.5.0](https://github.com/pytest-dev/pytest-asyncio/tree/1.5.0) - 2026-11-12

#### Added

- A `fixture-scope` value for `asyncio_default_fixture_loop_scope`. With it, an asynchronous fixture without `loop_scope` uses its `scope` as its loop scope. This is the behavior of an unset option in pytest-asyncio 1.x. ([#&#8203;1095](https://github.com/pytest-dev/pytest-asyncio/issues/1095))

#### Fixed

- Invalid arguments to the `asyncio` marker, including an invalid `loop_scope`, are reported with a message that names the test instead of a traceback. ([#&#8203;1584](https://github.com/pytest-dev/pytest-asyncio/issues/1584))
