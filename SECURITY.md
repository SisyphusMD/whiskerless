# Security

Report a vulnerability privately by email to security@bryantserver.com, not in an issue or pull
request: those are public.

Say what is affected (repository, file, and the release or commit), how to reproduce it, and what
you think an attacker could do with it. You will get a reply from the maintainer, and the fix and
its disclosure are coordinated with you.

Only the latest release is supported. A fixed vulnerability is recorded in the changelog of the
release that fixes it.
